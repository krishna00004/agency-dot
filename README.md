# Agency. – Responsive Landing Page

A modern and fully responsive agency landing page built using React.js with Dark and Light mode support.

## 🌐 Live Website 
[Visit Agency.](https://agency-dot.vercel.app)


## 🚀 Features
* Fully responsive design for mobile and desktop.
* Dark and Light mode toggle.
* Navigation links (Home, Services, Our Work, Contact Us).
* Modern and clean user interface.
* Smooth navigation between sections.

## 📂 Project Files
* `src/` - React components and application files.
* `public/` - Images and public assets.
* `App.jsx` - Main application component.
* `index.css` - Styling and layout.
* `package.json` - Project dependencies.
* `README.md` - Project information.

## 🛠️ How to Run
1. Download or clone this project.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL in your browser.
